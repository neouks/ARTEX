# 内置查询工具的模型视图

本次只调整 Agent 内置工具及其查询路径。前端 HTTP 接口、原始会话、事实正文、证据、凭证及任务审批模板不变。

## 列表

- `list_facts`、`list_findings`：默认 20，最多 100；返回 `facts` / `findings`、`total`、`has_more`、`next_before`。总数和分页先经过任务、来源及资产授权过滤。支持 `q`、`asset_id`，漏洞另支持 `severity`。
- `list_assets`：默认 10，最多 50；`id`、`ids`、`dsl` 三选一。默认摘要不读取认证、参数、DNS 大数组和 `extra`；不展示 URL 用户信息及查询串。详细模式最多 5 个 ID，字段组为 `identity`、`fingerprint`、`dns`、`params`、`auth`、`extra`，默认仅前两个。
- `list_worker_traces`、`search_all_worker_traces`：默认 20，最多 100；`before` 续页。继承任务仅暴露已结束意图的轨迹。
- `expand_index`：按原有代表资产规则直接查询，先授权再计数、分页；默认 20，最多 100。索引正文是摘要，完整正文通过 `expand_digest` 读取。
- 列表预算 24,000 字符；预算触发时保留完整记录并提供继续位置，不裁断序列化后的 JSON。

## 详情与续读

文本窗口默认 8,000、最多 24,000 字符，按 Unicode 字符计算。集合中的大字段返回明确的延期标记及 JSON Pointer；用该 `field` 继续读取。集合使用 `index` / `next_index`，文本使用 `offset` / `next_offset`。

```json
{"id":123,"field":"/evidence/poc","offset":8000}
```

上例用于 `node_detail`，字段相对节点的 payload。资产详情字段相对所选字段组，文本偏移参数名为 `text_offset`：

```json
{"id":123,"detail":true,"fields":["auth"],"field":"/auth/0/token","text_offset":8000}
```

`get_worker_output` 直接读取最新 `result`，缺少时读取最新 `text`，返回当前意图 `state` 和 `has_output`，不能把运行中输出视为已完成。数据库只返回本次请求的正文窗口。`get_worker_trace` 通过 `step_ids` 显式读取至多 5 个步骤正文，不能与关键词或摘要页游标混用。

批量详情共享响应预算，单段可能短于所请求上限；必须以实际返回的继续位置为准。所有原始数据均保留。

## 授权与历史

- 每次模型调用前重新批量核验资产、节点和审批管理分组，包含来源关系与授权变化。
- 同一规范化只读查询的同一页，仅保留最新成功结果正文。写操作、不同页、不同筛选及失败调用不合并；工具调用与返回配对、原始 transcript 不变。
- 历史计数明确标记为快照。历史审批查询只重新核验已有分组，不重复执行旧分页和计数查询。
- 态势查询内可复用授权及来源读取结果；该对象仅存在于本次调用的 ToolSet 副本，不跨调用缓存。
- 源任务的有限窗口计数命名为 `facts_in_window` / `findings_in_window`，不能冒充全量总数。查询失败应查看 `unavailable` 或对应错误字段，不能当作零资产或无发现。

## 本地验证数据

独立 PostgreSQL 测试库，未连接或修改业务数据库。以下是合成数据结果，不是生产压测或精确 Token 计量：

| 数据 | 原始读取 | 优化读取 |
| --- | --- | --- |
| 单资产包含大认证字段 | 76,288 字节 | 默认模型摘要 221 字节 |
| 1,000 条大正文事实中的一页 | 494,622 字节，约 21.7 ms | 数据库摘要投影 2,923 字节，约 12.1 ms |
| 三次相同长历史查询 | 108,577 字节 | 模型副本 36,769 字节 |

本次 10 个查询工具的定义合计 6,387 字节。计时受缓存和本机负载影响，不应作为生产 SLA。查询次数的关键变化是事实、漏洞及跨 Worker 搜索共用单语句授权分页，冷摘要和历史节点改为批量授权，不随返回记录逐条发起授权查询。
